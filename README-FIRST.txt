SVG Master · SVG 生成器  v1.4
================================================

【启动】
双击 svg-master.exe 即可，无需安装、无需注册表。
首次运行会在同级目录生成 data\ 文件夹，用来存配置和会话 SVG。
整个文件夹可以任意拷贝到别的电脑使用。

如果窗口没弹出来，说明本机缺 Microsoft Edge WebView2 运行时，
程序会自动改用系统默认浏览器打开界面（地址会打印在控制台）。

【三步出图】
1. 点左下「管理供应商」：
   选协议（OpenAI 兼容 / OpenAI Responses / Anthropic Messages / Gemini V1beta）
   → 填 Base URL 与 API Key → 点「获取模型列表」→ 勾模型 → 保存。
2. 主界面点右上角的模型徽标，选中刚配好的模型。
3. 在「提示词」里写你要的画面，或点「提示词库」挑一条模板，
   然后点「开始生成」。

默认提示词就是主题本身：
  A pelican riding a bicycle.
改这几个字就能换任意主题。「只交付 SVG 代码」属于系统提示词里的固定规范，
不用在「提示词」框里重复写。

【生成方式：三级开关】
左栏最上面是「生成方式」，可点击、也可按住左右拖动，三档：

  快速模式   一次性交付整幅 SVG，没有图层工具，最快。适合单图、图标。
  多图层模式 模型分多步、按图层创建与改造，可逐层返工。适合复杂画面。
  动图模式   仍然只有一个图层，但交付的是可播放的动图，可导出 GIF。
             适合加载动画、动效图标。

切换规则：
· 还没点过「开始生成」之前，三档可以随便来回切，刷新页面也不锁。
· 点过「开始生成」之后就锁：只有仍停在快速模式时还留最后一次切换机会，
  切走之后三档全部置灰、拖动也会被拒绝。
· 动图是单向门：在动图模式下点过「开始生成」，就再也切不回其他模式。
  出口是工程弹窗里的「快速生成」（它本来就是清空画板重开）。
· 当前画板还有多个图层时，切回快速或动图会提示先把图层删到 1 个。

【动图预览与导出 GIF】
动图模式下的 SVG 直接渲染在画布上，SMIL 动画（animate / animateTransform /
animateMotion / set）由浏览器原生播放，不需要额外插件。

画布下方会出现动图工具条：播放 / 暂停、帧率（1-30）、帧位置、导出 GIF。
导出 GIF 完全在前端完成：SVG → canvas 逐帧采样 → 内置 GIF89a 编码器，
零依赖、不经过后端、不需要联网。多帧分组动画（data-frame 图层）和 SMIL
动画两条路径都支持。

【工程与图层】
· 点顶栏「工程」可三选一：快速生成（空画板直接开工）/ 新建项目 / 打开项目。
  快速模式用内置临时文件夹，退出时可另存为正式工程或直接丢弃。
  工程模式绑定你选的文件夹，图层与对话即时落盘。
· 画板本来就空时，点「快速生成」直接进，不再多问一句「将清空图层与上下文」。
· 多图层模式下左栏有图层列表：点「＋」新建，点行选中当前层，
  眼睛图标切显隐，锁图标锁定该层（锁住后模型不能改），双击名字改名，
  「↑」「↓」调层级，「删」删层。
· 工程快照里带 empty 字段（所有图层无内容且无对话历史时为 true），
  前端据此决定要不要弹清空确认框。

【图转 SVG】
把图片拖到「图片输入（可选）」框里，或者粘贴 / 点击选择。
前端会自动缩到长边 1568px 再发给模型。
注意：所选模型必须支持图像输入（供应商面板里「视觉」那一列要显示「支持」）。

【界面速览】
- 顶栏：模型徽标（可点，切换该供应商下的模型）· 主题按钮 · 清理 · 复制 SVG · 保存 SVG
- 左栏：生成方式三级开关 · 提示词 · 比例预设 · 思考等级 · 图片输入 · 开始生成 · 代码
  · 管理供应商 · 提示词库
  连接信息（URL / Key / 协议）只在供应商弹窗里维护，主界面不显示。
- 中间：实时画布。左键拖动平移，滚轮缩放，双击复位，
  工具栏有「适应窗口」和「1:1」。
  点左栏「代码」可把画布切成源码面板：行号、缩进、折叠、自动换行、复制代码，
  快捷键 Ctrl + ` 来回切。
- 右栏：上下文用量（used/max、压缩块、TPS、tokens、模型轮/工具）
  + AGENT 参数（最大步数、自动校验、上下文压缩、非流式兜底、压缩阈值）
  + 原始输出（正文 / 思考 / 错误三段切换，底部显示字数，可单独清空）
- 两个标签页：生成 / 日志流。
  日志流里正文和思维链只显示摘要（行尾标「· N 字」），
  全文统一到右栏「原始输出」里看。

【清理】
顶栏「清理」会弹确认框，一次清空画板、日志、原始输出、已载入图片和当前会话上下文。
供应商与设置不受影响。

【主题】
默认跟随系统深浅色。点顶栏主题按钮循环：跟随系统 → 深色 → 浅色。

【思考等级】
默认 off / low / medium / high 四档。
在供应商面板勾选「扩展思考」后会多出 xhigh（极致）和 max（最大）两档。
没勾选时即使配置写了 xhigh/max，保存后也会自动降回 high。

【命令行参数】
  svg-master.exe                 打开窗口（默认）
  svg-master.exe -web            用系统浏览器打开，不开窗口
  svg-master.exe -port 8080      指定端口（默认随机空闲端口）
  svg-master.exe -data D:\mydata 指定数据目录
  svg-master.exe -debug          打开 WebView2 调试

【数据与隐私】
所有请求都是本机直接发给你填的 API 地址，不经过任何第三方。
API Key 落盘做了本机混淆（enc: 前缀，绑当前主机名），
界面回显一律打码；换机器或换数据目录后需要在供应商面板重填一次 Key。
data\sessions\ 下按会话保存每次交付的 SVG，可随时取走。

【常见问题】
· 提示「当前模型未标记支持图像输入」
  → 到供应商面板把该模型的「视觉」改成「支持」，或换一个视觉模型。
· 界面一直没反应，日志流只有一行就停
  → 多半是 Base URL 写错，或该网关不支持 SSE。勾上「非流式兜底」再试。
· 模型列表拉不下来
  → 有些中转站没实现 /models 接口，直接在供应商面板里手动加模型 id 即可。
· 生成的 SVG 有问题
  → 勾上「自动校验」，模型会拿到问题清单自己继续修。
· 切不动生成方式了
  → 已经点过「开始生成」，切换被锁。走工程弹窗的「快速生成」重置。
· 导出的 GIF 不动
  → 检查交付的 SVG 里是否有 animate 系列标签；纯静态图只有一帧。
